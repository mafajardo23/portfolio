# Hi, I'm Maria 👋

UX/UI designer and researcher based out of Davidson College, building toward a career in product design. This repo is the source for my portfolio site.

**🔗 Live site:** https://mafajardo23.github.io/portfolio/

## About this portfolio

I built this site from scratch, no template, no page builder, to have full control over how my work is presented and to prove I can execute a design system end to end: concept, visual identity, front-end build, and deployment.

The visual language is coastal minimalist: cream and sand backgrounds, sage green as the structural color, typography pairs Playfair Display for headings with Barlow for body text.

## Case studies

- **Ollie** — GenAI Chatbot for Dashboard
- **SportSpark** — End to end App Redesign (App Store)
- **AssemblyViz** — Web-based Assembly/RISC-V simulator full project 
- **The Blob Tree** — Full Case study for Mood Tracking App concept
- **Design Sprints** — a collection of rapid, timeboxed design exercises


Each case study walks through problem framing, process, and outcome, not just polished final screens.
